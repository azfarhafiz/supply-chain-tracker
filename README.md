# Supply Chain Track & Trace Dashboard

A full-stack supply chain tracking web application that allows users to monitor shipment details and status in real-time.

---

## 🛠️ Tech Stack

- **Frontend:** React JS
- **Backend:** Spring Boot (Java)
- **Database:** Oracle DB
- **Version Control:** Git & GitHub

---
